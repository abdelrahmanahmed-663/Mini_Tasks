AS Agent

Full-stack autonomous AI agent built in Python with Tkinter as the desktop GUI. Dual-backend architecture — Anthropic Claude API as primary, GPT-2 as offline fallback. Implements a full agentic reasoning loop: the system plans, decomposes tasks into sub-goals, executes multi-step actions, and self-corrects based on intermediate outputs.

NLP evaluation pipeline computes BLEU, ROUGE-L, perplexity, and cosine semantic similarity to quantify output quality. Word embeddings (Word2Vec, sentence-transformers) power intent classification and NER. Multi-turn coherence maintained via contextual encoding through HuggingFace Transformers.
